# 明白卡 · 手把手部署（小白版）

> 这份文档假设你**从没做过小程序**。  
> 不解释原理，只讲三件事：**在哪个地方** → **点哪里** → **看到什么算成功**。
>
> 技术细节和排错原理在另一份 `部署指南.md` 里，你现在**不用看**那份。

---

## 开始之前：先认清「两个地方」

这是小白最容易晕的一点——后面所有操作都在这**两个不同的地方**之一完成。每步我都会标明是哪一个。

| 简称        | 全称      | 是什么                    | 怎么打开                     |
| --------- | ------- | ---------------------- | ------------------------ |
| **网页后台**  | 微信公众平台  | 一个**网站**，管账号、看数据、提交发布  | 浏览器输入 `mp.weixin.qq.com` |
| **开发者工具** | 微信开发者工具 | 一个**装在电脑上的软件**，看效果、传代码 | 你的桌面或开始菜单里已经有了           |

> 简单记：**注册账号、上线发布在网页**；**看效果、传代码在软件**。

还有三个名词先认识一下，后面会反复出现，别怕：

| 名词        | 长什么样                                      | 从哪来                |
| --------- | ----------------------------------------- | ------------------ |
| **AppID** | `wx` 开头的一串字母数字，如 `wx1a2b3c4d5e6f7g8h`     | 注册完账号后，网页后台里能看到    |
| **环境 ID** | `你起的名字-随机串`，如 `mingbaika-prod-8g3k2m`     | 在开发者工具里点「开通云开发」后生成 |
| **上传密钥**  | 一个文件，名字像 `private.wx1a2b3c4d5e6f7g8h.key` | 网页后台里点「生成」后下载      |

## 你现在要做哪一步？

按顺序做，**不要跳**。每一步做完都有「成功标志」，看到了再往下走。

| 步骤        | 做什么                | 在哪做          | 大概耗时     |
| --------- | ------------------ | ------------ | -------- |
| **第 1 步** | 注册账号，拿到 AppID      | 网页后台         | 30 分钟    |
| **第 2 步** | 把代码导入开发者工具         | 开发者工具        | 15 分钟    |
| **第 3 步** | 开通云开发，填环境 ID       | 开发者工具        | 10 分钟    |
| **第 4 步** | 部署云函数              | 开发者工具        | 10 分钟    |
| **第 5 步** | 上传代码，**手机上打开看效果**  | 开发者工具 + 网页后台 | 15 分钟    |
| **第 6 步** | 配置隐私协议（不配的话核心功能报错） | 网页后台         | 10 分钟    |
| **第 7 步** | 备案                 | 网页后台         | 等待 3–5 周 |
| **第 8 步** | 提交审核 → 发布          | 网页后台         | 1–7 天    |

> **注意一个关键点**：第 1–6 步做完，你就能**在手机上打开这个小程序**（叫「体验版」）。  
> 第 7、8 步只是为了让**陌生人也能搜到它**。所以你在第 6 步就能看到成果，不用等几周。

---

## 第 1 步 · 注册账号，拿到 AppID

全部在**浏览器**里做。

### 1.1 准备三样东西

- 一个**邮箱**（必须是从没注册过微信公众号/小程序的邮箱，QQ 邮箱、163 邮箱都行）
- 你的**身份证**（要拍照上传）
- 你的**手机号**（要和你的微信号绑定的号码一致，后面要微信扫码验证）

### 1.2 注册

1. 浏览器打开 `mp.weixin.qq.com`
2. 右上角点「**立即注册**」
3. 选「**小程序**」（不是订阅号、不是服务号）
4. 填邮箱 → 设密码 → 点注册
5. 去邮箱收信，点里面的激活链接
6. 回到页面，**主体类型选「个人」**
   - 个人主体**免费**，够用。企业主体要花 300 元做微信认证，你不需要
   - 个人主体不能用微信支付、不能嵌外部网页——**明白卡这两样都不需要**
7. 填身份证信息、手机号，最后**用微信扫码**验证

### 1.3 填名称和类目

1. 名称：取一个，比如「明白卡」。**名称全平台唯一**，被别人用了就换一个
   - 注意：名称**一年只能改 2 次**，想好再填
2. 服务类目：选「**工具**」下面的**信息查询 / 效率**一类（以你后台实际显示的选项为准）
   - 类目必须和你小程序实际功能对得上，**选错会被审核驳回**

### 1.4 找到 AppID

1. 网页后台左侧菜单「**开发**」→「**开发管理**」→「**开发设置**」
2. 页面最上方「开发者 ID」区域，第一个就是 **AppID**，`wx` 开头

**成功标志**：你复制到了一串 `wx` 开头的字符。

> 把 AppID 记在记事本里，后面要用两次。

---

## 第 2 步 · 把代码导入开发者工具

现在换到**装在你电脑上的那个软件**。

### 2.1 打开软件

打开「**微信开发者工具**」，用**你自己的微信**扫码登录。

登录后你会看到一个项目列表（现在多半是空的）。

### 2.2 导入项目

1. 点右上角的「**导入**」两个字（**不是**中间那个大「+」）
   - 大「+」是「新建项目」，会给你一个空模板，不是我们要的
2. 「目录」那一栏，粘贴这个路径：
   ```
   C:\Users\nihao\Desktop\FJTravel\apps\mingbaika
   ```
   > **千万别选到下面的 `miniprogram` 文件夹**。要选 `mingbaika` 这一层。
3. 「AppID」那一栏：填第 1 步拿到的 AppID
4. 点「导入」

**成功标志**：左边文件列表里出现了**两个文件夹**——`miniprogram` 和 `cloudfunctions`；中间的模拟器里出现了明白卡的首页（大字、几个按钮）。

### 2.3 如果报错

| 报错                          | 怎么办                            |
| --------------------------- | ------------------------------ |
| AppID 不合法                   | 检查是不是少复制了几个字符，或者复制时带了空格        |
| 提示目录里没有 project.config.json | 你选错层级了，重新导入，选到 `mingbaika` 这一层 |
| 模拟器一片白                      | 点菜单栏「编译」刷新一下                   |

---

## 第 3 步 · 开通云开发，填环境 ID

还在**开发者工具**里。

### 3.1 开通

1. 点软件顶部工具栏的「**云开发**」按钮
2. 弹出窗口 → 点「**开通**」
3. 选套餐：选「**免费**」那个（基础版）
4. 环境名称：填 `mingbaika-prod`
5. 点创建，等一两分钟

创建完会自动打开「**云开发控制台**」（一个新的网页/窗口）。

### 3.2 抄下环境 ID

在云开发控制台里，找到**环境 ID**（形如 `mingbaika-prod-8g3k2m`），复制下来。

### 3.3 填进代码

1. 回到开发者工具
2. 左边文件列表，依次点开 `miniprogram` → `app.js`
3. 找到**第 5 行**，长这样：
   ```js
   var ENV_ID = 'YOUR_ENV_ID';
   ```

4. 把 `YOUR_ENV_ID` 换成你刚才复制的环境 ID（**引号保留，不要删**）：
   ```js
   var ENV_ID = 'mingbaika-prod-8g3k2m';
   ```
5. 按 `Ctrl + S` 保存

### 3.4 建一个「集合」（数据存的地方）

1. 回到云开发控制台
2. 左侧点「**数据库**」
3. 点「**+**」新建集合，名字填 `notices`（全部小写，一个字母都不能错）
4. 权限选「**仅创建者可读写**」

**成功标志**：`app.js` 里的 ENV_ID 不再有 `YOUR_` 字样；数据库列表里能看到 `notices`。

> **不想手点？可以让脚本代劳**
>
> ```bash
> export WX_APPSECRET=你的AppSecret    # Git Bash；CMD 用 set，PowerShell 用 $env:
> node scripts/setup-db.js
> ```
>
> 脚本走微信官方云开发 HTTP API（`tcb/databasecollectionadd`）替你建。
> AppSecret **只从环境变量读**，不落盘、不打印、不进 git——所以别把它贴进任何聊天或文档。
>
> 注意：API 只管「建」，**不带权限参数**，所以建完仍然要按上面第 4 点去控制台核对权限。

---

## 第 4 步 · 部署云函数

云函数是「跑在云端的一段程序」，明白卡靠它把通知变成卡片。

还在**开发者工具**里。

1. 左边文件列表，展开 `cloudfunctions` → 找到 `parseNotice` 这个文件夹
2. **右键点它** → 选「**上传并部署：云端安装依赖（不上传 node_modules）**」
3. 右下角会出现进度提示，等 1–3 分钟

**成功标志**：底部提示「上传成功」；在云开发控制台左侧「云函数」里能看到 `parseNotice`。

> 如果这里的菜单项名字和上面不完全一样（工具版本不同措辞略有差异），选**带「上传并部署」和「云端安装依赖」字样**的那一项就对了。

---

## 第 5 步 · 上传代码，在手机上打开看效果

这一步做完，你就能拿手机玩它了。

### 5.1 上传

1. 开发者工具右上角点「**上传**」
2. 版本号填 `0.1.0`
3. 项目备注填「第一个版本」
4. 点「上传」，等一会儿

**成功标志**：提示「上传成功」。

### 5.2 设成体验版

换到**网页后台**：

1. 左侧菜单「**管理**」→「**版本管理**」
2. 在「**开发版本**」区域，能看到刚才上传的那条记录
3. 点它右边的「**选为体验版**」
4. 弹出一个二维码，用**手机微信扫它**

**成功标志**：手机微信里打开了明白卡，能看到首页。

### 5.3 让别人也能打开（可选）

网页后台 →「管理」→「成员管理」→ 体验成员，把别人的微信号加进来，他们也能扫同一个二维码打开。

**还没完——现在先别急着往下走。**

到这里你已经能打开界面了，但**点「从聊天记录选图」很可能是报错的**。原因是第 6 步还没做。

## 第 6 步 · 配置隐私协议（必须做，否则核心功能报错）

明白卡要读你在微信聊天里的图片，微信规定：**必须在后台声明这个能力，并且在用户面前有明确说明**，否则调用时会直接报错。

在**网页后台**：

1. 左侧菜单「**设置**」→「**基本设置**」
2. 找到「**用户隐私保护指引**」→ 点「**更新**」
3. 在能力清单里，勾选用到的那几项：
   - 「**选择聊天文件**」（最重要，核心入口靠它）
   - 「**相册（仅写入）权限**」——如果用到保存图片
   - 「**摄像头**」——如果用到拍照
4. 每一项都要填**用途说明**。照实写，比如：
   - 选择聊天文件 →「用于读取您从聊天中选择的通知图片，并解析成行动清单」
5. 提交，等审核通过（一般 1–3 天）

**成功标志**：隐私指引状态显示「已通过」。

### 审核期间你可以先测别的

- 点首页的「**拍照 / 从相册选图**」按钮 → 这条不依赖隐私协议，应该能用
- 随便选一张有字的照片（比如作业通知），看能不能出卡片

## 第 7 步 · 备案（只有"正式上线"才需要）

**这一步不影响你测试**。体验版、真机测试、录演示视频，全都不需要备案。

只有当你想让**陌生人也能搜到你的小程序**（也就是"正式上线"）时，才必须先备案。

### 什么时候做

越早越好，因为它**要等 3–5 周**，而且不能催。

### 怎么做

1. 网页后台左侧「**设置**」→「**基本设置**」→ 找到「**小程序备案**」→ 点「**去备案**」
2. 按引导填：
   - 身份证正反面（清晰、四个角都在、不要反光）
   - 手机号（**必须和你微信绑定的号一致**，否则验证失败）
   - 通信地址（**要写到门牌号**，只写到"某条路"会被驳回）
   - 人脸核身（白墙前拍，不戴帽子口罩）
3. 提交后注意：
   - 微信先审 1–2 天
   - 然后会收到 **12381** 发来的短信，**必须在 24 小时内完成短信核验**，超时整个备案作废、要重新提交
   - 之后是各省通信管理局审 7–20 个工作日

**成功标志**：网页后台能看到备案号。

---

## 第 8 步 · 提交审核 → 发布

备案通过后，就可以让所有人用了。

1. 网页后台「**管理**」→「**版本管理**」
2. 找你要发布的版本 →「**提交审核**」
3. 提交前自己检查这几条（都是被驳回的高频原因）：
   - 服务类目和实际功能一致
   - 首页写得清楚"这个小程序是干什么的"（审核员看不到你的方案文档，只能看小程序本身）
   - 隐私协议已通过
4. 审核通过后 → 点「**发布**」

**成功标志**：网页后台显示「已发布」，别人能搜到你的小程序了。

## 卡住了怎么办

先把报错原文复制下来问，别只看现象。下面是常见的几个：

| 你看到的                                             | 真正的原因             | 怎么办                            |
| ------------------------------------------------ | ----------------- | ------------------------------ |
| `scope is not declared in the privacy agreement` | 第 6 步没做           | 去网页后台配用户隐私保护指引                 |
| `wx.cloud is not defined`                        | 基础库太旧             | 开发者工具右上角「详情」→「本地设置」→ 调高调试基础库版本 |
| 点解析没反应 / 报环境不存在                                  | 第 3 步的 ENV_ID 没填对 | 回 `app.js` 第 5 行核对，和环境 ID 一模一样 |
| `cloud function not found`                       | 第 4 步没做成功         | 重新右键 `parseNotice` 上传部署        |
| 解析出来一张空卡片                                        | 模型没配好或额度问题        | 先看 `docs/AI接入选型.md`，或问我要具体报错   |

> 任何一步卡住，**把屏幕截图发我**，我帮你看是哪一环。

**第 1–6 步做完，你手上就有一个能用的明白卡**，可以在手机上给别人演示。  
第 7、8 步只是"上架"，需要等，但不影响你开发和测试。
