## 工程依赖在哪（改动前必读）

`miniprogram-ci` 等部署依赖装在**工作区根目录** `C:\Users\nihao\Desktop\FJTravel\node_modules`，
**不在小程序项目目录里**。

**为什么**：它有 276M / 22763 个文件。放在小程序项目目录下会显著拖慢微信开发者工具的
导入和文件索引，还会触发多余的 npm 处理逻辑。

**注意**：需要时用下面的命令装，**不要在项目目录里 `npm install`**（会把巨型依赖重新塞回项目目录）：

```bash
cd C:/Users/nihao/Desktop/FJTravel     # 工作区根目录，不是 apps/elder-notes
npm install
```

Node 的模块解析会逐级向上查找，所以 `scripts/deploy.js`、`scripts/check.js` 照常能找到依赖。
`deploy.js check` 里也实现了向上查找（函数 `findUpwards`），不会因为依赖不在本目录而误报"没安装"。

## 0. 两条路，选一条就行

| | **路线 A：开发者工具上传** | **路线 B：脚本上传（miniprogram-ci）** |
|---|---|---|
| 需要密钥 | **不需要** | 需要 |
| 需要 IP 白名单 | **不需要** | 需要 |
| 适合 | 一次性手动上传（**推荐，和明白卡 v1 的做法一样**） | 自动化 / CI / 批量发布 |

微信官方文档对 miniprogram-ci 的说明是「上传代码，**对应小程序开发者工具的上传**」——
两者等价，密钥只是给"不打开开发者工具"这条路的。

**明白卡 v1 当初就是用路线 A 上的体验版，全程没有密钥。** 想省事就直接走 A。

## 路线 A · 用开发者工具上传（推荐）

1. 打开**微信开发者工具**（用管理员微信扫码登录）
2. **导入项目**：
   - 目录选 `C:\Users\nihao\Desktop\FJTravel\apps\elder-notes`
     （⚠️ 选这一层，里面有 `project.config.json`；**不要**选到 `miniprogram/`）
   - AppID 填 `wx77fb4239f60954f0`（项目配置里已写好，一般会自动带出）
   - 后端服务选「**不使用云服务**」——本项目数据全存本地，不用云开发
3. 等编译完成，点右上角 **「上传」**
4. 版本号填 `0.1.0`，备注填「记得 首个体验版」→ 确定
5. 上传成功后去 **mp.weixin.qq.com → 管理 → 版本管理**
   → 在「开发版本」里找到刚传的 → 点 **「设为体验版」**
6. 页面会出体验版二维码，微信扫码即可在手机上打开

> 管理员、开发者、体验成员都能扫。你自己是管理员，默认可以。

## 路线 B · 用脚本上传（需要密钥）

### B1. 生成代码上传密钥（约 2 分钟）

1. 浏览器打开 **mp.weixin.qq.com**，用小程序管理员微信扫码登录
2. 左侧菜单：**管理** → **开发管理** → **开发设置**
3. 找到 **「小程序代码上传」** 区块 → 点 **「生成」**
4. 下载密钥文件，文件名形如 `private.wx77fb4239f60954f0.key`
5. 把文件放到 **`apps/elder-notes/` 根目录**（和 `project.config.json` 同级）

> ⚠️ 密钥**只下载一次**，关掉弹窗就没了。丢了只能重新生成。
> 该文件已被 `.gitignore` 排除（`*.key`），不会进 git。

---

### B2. 配置 IP 白名单（不做这一步上传必失败）

同在 **开发管理 → 开发设置 → 小程序代码上传** 页面：

1. 点 **「IP 白名单」** 的编辑
2. 填你当前的公网 IP
   - 不知道就打开 https://myip.ipip.net 或搜「我的 IP」，首页会直接显示
3. 保存

> 家庭宽带 IP 会变。上传报 `errCode` 且提示 IP 不在白名单时，重新查一次再改。

---

### B3. 上传

```bash
cd apps/elder-notes
node scripts/deploy.js upload 0.1.0 "记得 首个体验版"
# 或用 npm：
npm run deploy:upload
```

成功会显示 `上传成功：version=0.1.0 desc=记得 首个体验版`。

想先生成二维码在手机上试：

```bash
node scripts/deploy.js preview     # 生成 preview-qrcode.jpg，微信扫码打开
```

## 提审 / 正式发布（脚本做不了）

上传完成后去 **mp.weixin.qq.com → 管理 → 版本管理**：

- **设为体验版** → 立即可用，体验成员扫码就能打开（**不需要备案**）
- **提交审核 → 发布正式版** → ⚠️ **必须先取得 ICP 备案号**（没备案连提审都过不去）

> **备案既约束提审，也约束发布；但完全不影响体验版。**
> 个人主体备案通常 7–20 个工作日（含 1–2 天平台初审 + 24 小时内工信部短信核验 + 管局终审）。
> 距 10/17 只剩 8 天（今天是 10/9），备案号来不及——**这届交付体验版即可**。

## 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `ip not in whitelist` / errCode 相关 | IP 白名单没配或 IP 变了 | 重查公网 IP，改白名单 |
| 密钥与 AppID 不匹配 | 拿错小程序的密钥 | 重新生成，确认 AppID 是 `wx77fb4239f60954f0` |
| `MODULE_NOT_FOUND: miniprogram-ci` | 依赖没装 | `npm install` |
| `ERR_INVALID_ARG_TYPE` | APPDATA 为空 | 脚本已自动兜底；仍失败就手动 `export APPDATA="$USERPROFILE\AppData\Roaming"` |

## 附：为什么还要保留脚本路线

开发者工具的**图形界面完全可用**（路线 A），**坏掉的只是它的命令行接口**——
CLI 会尝试监听 `127.0.0.1:3799`，该端口落在 Windows 保留端口段（3713–3812）内，
在本机直接 `EACCES` 失败，所以我没法从命令行驱动它。

`miniprogram-ci` 的意义是：**不需要打开开发者工具也能上传**（自动化 / CI / 批量发布），
代价是要密钥和 IP 白名单。一次性手动上传的话，路线 A 更简单。
