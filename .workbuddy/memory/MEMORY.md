## 项目定位

工作区下有三条产品线。前两条为**福建主题**，第三条是**独立赛道**（非福建主题），
三者按赛道 / 用户 / 场景 / 数据四维度互不重叠，只共用工程基建（云开发、TDesign）。

1. **遇光（yuguang-travel-app）** — 全栈旅行应用
   - 后端：Spring Boot（已覆盖 107 个 API）
   - 移动端：Flutter
   - 后台管理：Vue3
   - 附加模块：React + Three.js 3D 文物展示（assets 含 8 个中国文物 GLB 模型，置于 `public/models/`）
   - 占据赛道：**文旅 / 旅行服务**
2. **闽游蛙（暂定名）** — 模仿《旅行青蛙》的福建主题微信小程序游戏
   - 核心玩法：角色自主出游 / 寄回明信片 / 收集特产 / 好友互动
   - 福建元素融入目的地、道具与剧情（土楼、武夷山、闽南文化、地方美食）
   - 载体已定：**原生微信小程序 + TDesign**（非小游戏），详见 `docs/闽游蛙-载体选型备忘.md`
   - 占据赛道：**休闲游戏 / 收集养成**
3. **明白卡** — 面向隔代照护祖辈家长的群通知解构工具（2026-10-08 立项）
   - 核心：把家长群通知解构成行动卡（做什么 / 何时前 / 交多少 / 带什么 / 有无风险），
     大字 + 语音播报 + 一键拨号；入口只有"长按转发"一个动作
   - 立项立论：数字鸿沟的真形态不是"不会用手机"，而是"群里的书面语看不懂"——
     老人操作层没问题，卡在**信息层**
   - 占据赛道：**信息无障碍 / 家庭照护工具**；为 2026 微信小程序开发大赛专门设计
   - 明确不做：IM、AI 聊天助手、家长 App、健康医疗（后者同时是避开资质门槛的手段）
   - 详见 `docs/参赛项目-明白卡-方案.md`

## 本机环境约定

- Shell 用 **Git Bash**（用户习惯），但 `cmd.exe` 被安全策略禁止从 Bash 调用。
- **Java 项目在 Git Bash 下必须用 `scripts/mvn.sh` 构建**，直接用 `mvn` 会因路径未转换而
  `ClassNotFoundException`。详见 `docs/环境体检报告.md`。
- 工具链版本：Node 22.22.2 / Flutter 3.44.6 / Dart 3.12.2 / JDK 21.0.11 / Maven 3.9.10。
- `JAVA_HOME`、`M2_HOME`、`MAVEN_HOME` 在本机均为空。
