## 四、已知问题与规避

### Maven 在 Git Bash 下无法启动

现象：

```
$ mvn -v
错误: 找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher
原因: java.lang.ClassNotFoundException: org.codehaus.plexus.classworlds.launcher.Launcher
```

原因（已定位并复现）：`mvn` 的 shell 启动器**未把 POSIX 路径转换成 Windows 路径**，
直接把 `/d/development/apache-maven-3.9.10/...` 交给 Windows 版 `java.exe`，
类路径自然解析不到 `plexus-classworlds-*.jar`。
注：`M2_HOME` / `MAVEN_HOME` / `JAVA_HOME` 在本机均为空，但这不是根因。

规避方式 —— 用本仓库的包装脚本：

```bash
scripts/mvn.sh -v
scripts/mvn.sh clean package -DskipTests
```

若在 PowerShell / CMD 中工作，直接调用 `mvn` 或 `mvn.cmd` 即可，无此问题。

详细体检结论见 `docs/环境体检报告.md`。
